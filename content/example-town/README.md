# Example Town

A tiny original town for SARE: textured ground, roads, coloured buildings, a
jump ramp, stairs, flowers you can walk through (`NOCOL_Flowers`) and
invisible walls at the edge (`COL_EdgeWalls`).

Everything is generated by [`tools/make-example-pack.py`](../../tools/make-example-pack.py);
there are no third-party assets. Licence: CC0-1.0 (public domain).

To make your own world, copy this folder, change `content.json`, and replace
`world.glb` with your own Blender export. See
[docs/content-packs.md](../../docs/content-packs.md).
