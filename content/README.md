# Content packs

Each folder here with a `content.json` is a SARE world that runs without GTA
San Andreas game files. The launcher lists them on **Home → Content packs**.

- [`example-town`](example-town) is a small original example to copy.
- How to make your own: [docs/content-packs.md](../docs/content-packs.md).

Only add files you made or may share, and never files from Rockstar games.
