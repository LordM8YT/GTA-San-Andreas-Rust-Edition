# SA Runtime — Grove Street-test

## Nyeste freeroam-versjon – 6. oktober 2026

Start **start-freeroam.cmd**. Native-versjonen starter i gåmodus og laster
nye nabolag mens du beveger deg. Hurtigtastene **1–9** laster Grove Street,
Los Santos sentrum, stranden, flyplassen, landsbygda, San Fierro, Las Venturas,
ørkenen og Mount Chiliad. **P** bytter til flykamera; **R** går tilbake til Grove.

Missions er satt til side. Native mods støtter egne DFF-modeller, TXD/PNG,
COL og kartplasseringer. Kjørbare biler, animerte peds, klær på spilleren og
multiplayer gjenstår. Se [freeroam-status](docs/freeroam-status.md) og
[native mods](docs/native-mods.md) for kontroller, tester og grenser.
