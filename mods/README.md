# Native mods

For native free roam, see the [native mod guide](../docs/native-mods.md). The
Rust runtime supports documented `mod.json` resources and selected assets,
including custom DFF/TXD/COL files, placements, and supported player and vehicle
resources. The guide describes the formats, setup, and current limitations.

Mods are data resources only. The runtime does not execute mod scripts or DLLs.
