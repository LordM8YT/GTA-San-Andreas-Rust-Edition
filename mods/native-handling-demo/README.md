# Native handling example

This disabled resource tunes the original Taxi, Infernus and Admiral through
native settings. It contains no game models or textures. The sample values are
illustrative native tuning, not copied GTA IV/V physics or translated SA
handling.cfg/FiveM handling.meta.

Enable in resource.json and restart the game or server. Server guests download
only this small manifest and use their own installed original models. All
omitted values use the prototype defaults. See docs/vehicle-dynamics.md for
units and limits. Later enabled resources overwrite earlier profiles for the
same lowercase model name. Profiles affect existing vehicle choices; registering
one does not add a new spawnable model to the car catalog.
